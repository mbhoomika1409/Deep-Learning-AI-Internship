The Spiral Challenge: a linear model compared with neural networks (with and without nonlinear activations) on a two-spiral dataset. Experiments on hidden-layer size, learning rate and activation (24 networks), a comparison table, test metrics with confusion matrices, and an explanation of which model performed best and why.
